# Black Meet (Black Meet) — سایت تماس صوتی/تصویری گروهی

یک سیستم تماس گروهی (مشابه Google Meet) با PHP (بک‌اند)، WebRTC (فرانت‌اند) و سرور سیگنالینگ
Socket.IO (Node.js). شامل احراز هویت دو مرحله‌ای (شماره تلفن + کد تأیید / ایمیل + رمز عبور)،
مدیریت تماس‌ها، چت، اشتراک‌گذاری صفحه، ایموجی زنده و کنترل دسترسی مبتنی بر نقش (ادمین/عضو).

---

## پیش‌نیازها
- **XAMPP** (Apache + MySQL) — PHP ۷.۴ به بالا (این پروژه روی PHP ۸.۲ تست شده).
- **Node.js** نسخه ۱۸+ (برای سرور سیگنالینگ).
- مرورگر مدرن (Chrome/Edge/Firefox) با پشتیبانی WebRTC.

---

## نصب و راه‌اندازی

### ۱. قرار دادن فایل‌ها
پوشه پروژه را در مسیر زیر کپی کنید:
```
C:\xampp\htdocs\black-meet
```
(آدرس نهایی: `http://localhost/black-meet`)

### ۲. راه‌اندازی دیتابیس
۱. پنل **XAMPP Control Panel** را باز کنید و روی دکمه‌های **Start** مقابل **Apache** و **MySQL** کلیک کنید.
۲. وارد **phpMyAdmin** شوید (`http://localhost/phpmyadmin`).
۳. یک پایگاه داده جدید به نام `blackmeet` با کدگذاری `utf8mb4` ایجاد کنید.
۴. روی پایگاه داده کلیک کرده و از منوی **Import**، فایل
   `sql/schema.sql` را وارد کنید.

   یا از خط فرمان:
   ```bash
   mysql -u root -p blackmeet < sql/schema.sql
   ```

### ۳. تنظیمات
فایل `config.json` را باز کنید و مقادیر را با محیط خود تنظیم کنید:
```json
{
  "db":   { "host": "localhost", "name": "blackmeet", "user": "root", "pass": "" },
  "secret": "یک-رشته-تصادفی-طولانی",
  "socket_port": 3000,
  "base_url": "http://localhost/black-meet"
}
```
> نکته: فایل `config.json` از طریق وب مسدود شده است (در `.htaccess`).

### ۴. نصب وابستگی‌ها و اجرای سرور سیگنالینگ
در پوشه پروژه:
```bash
npm install
node server.js
```
پیام `Black Meet signaling server listening on http://localhost:3000` نشان‌دهنده موفقیت است.
این پنجره باید باز بماند (سرور سیگنالینگ همیشه باید در حال اجرا باشد).

### ۵. باز کردن سایت
مرورگر را باز کنید و بروید به:
```
http://localhost/black-meet
```

## حساب مدیر (پیش‌فرض)
هنگام ایمپورت `schema.sql` یک حساب مدیر ساخته می‌شود.

رمز عبور به‌صورت هش‌شده (bcrypt) در دیتابیس ذخیره شده است.

## نحوه استفاده
1. **ثبت‌نام / ورود:** در صفحه اصلی بین ورود با شماره/ایمیل و ثبت‌نام جابه‌جا شوید.
   کد تأیید به‌صورت آزمایشی هم در سایت نمایش داده می‌شود و هم در دیتابیس ذخیره می‌گردد.
2. **ایجاد تماس:** از داشبورد روی «ایجاد جلسه جدید» کلیک کنید، عنوان را وارد کرده و ادامه دهید.
   یک لینک عمومی دریافت می‌کنید.
3. **پیوستن با لینک:** لینک یا کد تماس را در باکس جستجوی داشبورد وارد کنید و Enter بزنید.
4. **اتاق تماس:**
   - دوربین / میکروفون / اشتراک صفحه را کنترل کنید.
   - چت در سمت چپ، لیست اعضا و تب ادمین در سمت راست.
   - کاربران جدید باید توسط **ادمین** (سازنده تماس) تایید شوند.
   - ادمین می‌تواند اعضا را **حذف** یا **ساکت** کند.
   - دکمه ایموجی یک پاپ‌آپ باز می‌کند و ایموجی انتخابی ۲ ثانیه برای همه نمایش می‌یابد.

## امنیت
- رمزهای عبور به‌صورت متن‌ساده (plaintext) ذخیره می‌شوند — **غیرامن**، فقط بر اساس درخواست مالک. ورود با ایمیل هر دو فرمت متن‌ساده و هش bcrypt قدیمی را می‌پذیرد.
- کدهای تأیید با زمان انقضا (۵ دقیقه) در دیتابیس ذخیره می‌شوند.
- عبور از فیلتر `htmlspecialchars` برای جلوگیری از XSS.
- توکن CSRF در تمام فرم‌ها.
- دسترسی به صفحات داخلی فقط با نشست (Session) معتبر.
- ارتباط سوکت توسط توکن HMAC (با `secret` مشترک) تأیید می‌شود.
- فایل `config.json` از دسترسی وب مسدود است.

## عیب‌یابی
- **صفحه سفید / خطای پایگاه داده:** مطمئن شوید MySQL در XAMPP روشن است و دیتابیس `blackmeet` ایمپورت شده.
- **تماس برقرار نمی‌شود:** سرور `node server.js` باید در حال اجرا باشد و پورت ۳۰۰۰ باز باشد.
- **دوربین/میکروفون باز نمی‌شود:** اجازه دسترسی را در مرورگر بدهید؛ برای شبکه‌های مختلف اینترنتی به سرور TURN نیاز است (در حال حاضر فقط STUN عمومی پشتیبانی می‌شود).
- **مشکل زمان اجرا روی اینترنت:** در `server.js` و کلاینت (`assets/js/call.js`) آرایه `ICE` را با سرور TURN خود تکمیل کنید.
